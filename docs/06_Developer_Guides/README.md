# Developer Guides Map

本目录承载 build-for-agent 的开发、测试、运维和控制台操作指南。

推荐阅读顺序：

1. `Backend_Python_Dev_Guide.md`
2. `Gateway_Environment_Configuration.md`
3. `Backend_Unit_Testing_Guide.md`
4. `Agent_SDK_Quickstart.md`
5. `V2_Deposit_Indexer_Runbook.md`
6. `Website_User_Guide.md`

统一术语：

1. `Owner`：根身份
2. `Agent`：运行时调用主体
3. `Provider`：Owner 的供给侧业务角色
4. `Platform Gateway`：统一鉴权、路由、记账、审计执行层

本目录不再保留旧角色对照式写法。若代码中仍有历史命名，应理解为待重构实现细节，而不是产品或运维主视角。
