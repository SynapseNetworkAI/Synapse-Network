# Synapse Console User Guide

面向对象：

1. Owner 在 Agent / Consumer Workspace 中管理入金、Agent、预算、退款
2. Owner 在 Provider Workspace 中管理服务、收益、提现、审核状态
3. 平台运营人员查看审计、对账和告警

## 1. Agent / Consumer Workspace

1. Connect wallet and create session
2. Add funds to vault
3. Create Agent and issue credential
4. Discover and invoke services
5. Review spend and request refund

## 2. Provider Workspace

1. Register service manifest
2. Observe service health and invocation volume
3. Review provider receivable and locked balances
4. Submit withdrawal request
5. Track review or onchain completion status

## 3. Shared Owner Pages

1. Identity / Session
2. Wallet / Vault
3. Finance Overview
4. Unified Audit Timeline

## 4. Core Reading Rule

同一个 Owner 可以同时消费和供给。控制台的切换是 workspace 切换，不是身份切换。
