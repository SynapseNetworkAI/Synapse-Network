# Archive 文档说明

这个目录只保留历史方案、过渡期设计和已经被 canonical 文档替代的旧资料。

## 目录约定

- `pre_agent/`: 以 Buyer / Wallet / 旧发现模型为中心的历史文档。
- `historical_schema/`: V2 过渡期 schema、重构计划、旧数据库方案。
- `historical_architecture/`: 已被当前 Agent Runtime 主架构替代的旧总览文档。

## 使用规则

1. `archive/` 中的文档不再作为当前设计和开发依据。
2. 需要追历史决策、迁移脉络、旧术语来源时才进入这里查。
3. 如果某份历史文档仍有部分有效内容，应把有效内容合并回 active 文档，而不是重新把 archive 文档抬回主入口。
4. 新的过时文档统一移入这里，不要直接散落在 `docs/` 主目录。
