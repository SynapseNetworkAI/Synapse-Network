我们将整个生命周期分为 四大阶段，并且明确区分链上（On-chain，慢但安全）和链下（Off-chain，极速且免费）：

🟢 阶段一：充值与授信（On-chain 上链 ➡️ 转化为 Off-chain 凭证）
【目标】：把买家的真金白银锁进金库，给 AI 发放“通行证”。

连接主钱包（Master Wallet）： 买家（老板）在前端 Dashboard 连接 MetaMask。
链上充值（Deposit）：
买家点击“充值”，调用 Synapse Network 智能合约的 deposit(500 USDC) 方法。
（买家支付 Gas 费） 500 USDC 从买家钱包转入咱们的智能合约金库（Vault）并锁定。
平台记账（Indexer监听）：
咱们后端的 Python 脚本监听到链上 Deposit 事件成功。
立刻在中心化数据库中更新：买家老板账号 余额 = 500。
生成 AI 凭据（授信/配额）：
买家在后台给自己的 AI 创建一个 Agent_ID，并分配额度（比如最多花 100 刀）。
系统生成一个 JWT Token（即 X-Agent-Credential），交给买家的 AI 代理。
至此，准备工作完成。AI 随时可以出发。

阶段串联原则（必须）：
- 只有当链上 `Deposit` 事件被 Indexer 确认并完成数据库入账后，余额才进入可消费状态。
- 只有当 AI 持有有效 `X-Agent-Credential` 且未超授信额度时，才允许进入阶段二扣款路径。

实现字段映射（与技术文档统一）：
- 幂等键使用 `request_id`（请求头 `X-Request-Id`）。
- 可消费余额使用 `available_balance`。
- 单价/手续费/净收入使用 `unit_price` / `platform_fee` / `seller_net`。
- 凭据状态使用 `credential_status`（`active | revoked | expired`）。

🟡 阶段二：高频业务调用（纯 Off-chain 链下，毫秒级流转）
【目标】：AI 开始干活，平台网关作为“收费站”极速放行。

AI 发起请求： 买家的 AI 带着任务，向咱们的 Synapse Network 网关发送 HTTP 请求，Header 里带上 X-Agent-Credential。
网关拦截与鉴权（网关层）：
咱们的网关瞬间校验 JWT，并查询数据库：这个 AI 背后的买家余额够不够、授信额度是否充足？（假设他要调用的 API 标价是 0.05 USDC）。
极速扣款与分账（数据库层）：
余额充足！系统在内存/数据库里执行原子扣款：
买家余额 -0.05 (剩余 499.95)
平台抽水 +0.0005 (咱们赚 1%)
卖家余额 +0.0495 (卖家赚 99%)
（这一步极其关键：不碰区块链，0 Gas，耗时不到 10 毫秒！）
转发与响应：
扣款成功后，网关立刻把请求转发给后端的卖家 API（比如获取天气）。
卖家 API 吐出数据，网关把数据原路返回给买家 AI。
返回的 Header 里带上对账信息：X-Synapse-Cost: 0.05, X-Synapse-Balance: 499.95。
🔵 阶段三：控制台对账（纯 Off-chain）
【目标】：让买卖双方随时看到流水，建立平台信任。

买家视角： 登录 Dashboard，看到自己的剩余额度是 $499.95，下面有一条极细的流水：“今天 14:00，调用天气 API 花费 $0.05”。
卖家视角： 登录 Dashboard，看到自己的待提现余额是 $0.0495，看到有 1 次接口被调用。
平台视角（你/God View）： 你能看到沉淀资金池里有 500 USDC，其中 0.0005 是你实打实的利润。
🔴 阶段四：链上结算与退款（Off-chain 银票 ➡️ On-chain 提现）
【目标】：把账面数字变成真金白银，落袋为安。

场景 A：卖家提现（赚够了要走）

卖家点击“提现 $100”。
后端验证无误，将他数据库的 $100 余额清零。
后端用平台私钥签发一张“EIP-712 取款银票”（Signature）返回给前端。
卖家前端唤起钱包，自己花 Gas 费 调用合约的 claim(100, signature)。
合约验签通过，从金库里放出 100 USDC 到卖家钱包。
场景 B：买家退款（余额不想玩了）

买家点击“退回剩余余额 $400”。
后端验证无误，将他数据库的 $400 余额清零（防止他白嫖接口）。
后端签发一张“退款银票”给前端。
买家前端唤起钱包，自己花 Gas 费 调用合约的 refund(400, signature)。
合约验签通过，把 400 USDC 原路退回给买家主钱包。
