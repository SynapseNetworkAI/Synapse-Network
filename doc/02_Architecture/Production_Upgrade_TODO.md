# Synapse 升级到生产环境 TODO（存储与资金安全专项）

本清单用于把当前系统从开发态推进到可对外生产运行。

## P0（必须完成，未完成禁止上线）

## 1. 数据库与连接
- [ ] 使用托管 PostgreSQL（独立实例，非本地容器）
- [ ] 开启 TLS 连接与最小权限账号（读写分离账号策略）
- [ ] 连接池参数落地（最大连接数、超时、重试）

## 2. 资金事务与并发安全
- [ ] 所有扣费/结算路径使用单事务提交
- [ ] 余额读取使用 SELECT ... FOR UPDATE
- [ ] 拒绝负数金额与异常精度（统一 Decimal 精度规则）
- [ ] 每笔资金动作记录 request_id 并做唯一约束
- [ ] 失败回滚路径有单元测试覆盖

## 3. 幂等与防重放
- [ ] API 层要求幂等键（request_id）
- [ ] 数据库层唯一索引防重复入账
- [ ] 重放请求返回已处理结果，不重复扣款

## 4. 审计与追踪
- [ ] 关键账本字段完整：request_id, owner, actor, amount_delta, balance_before, balance_after, result, ts
- [ ] 日志禁止输出 token/secret/私钥材料
- [ ] 错误返回对外最小披露，不暴露内部堆栈

## 5. 备份与容灾
- [ ] 每日全量备份 + WAL 增量备份
- [ ] 明确 RPO/RTO 目标并文档化
- [ ] 至少一次完整恢复演练并记录结果
