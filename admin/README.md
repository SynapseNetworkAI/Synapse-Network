# Admin Workspace

`admin/` 目录用于承载平台管理后台的独立代码，与交易网关 `gateway/` 做边界隔离。

## 目录入口

1. 后台项目导航：`docs/03_Projects/admin-front/README.md`
2. 后台控制面导航：`docs/03_Projects/gateway-admin/README.md`
3. 后台系统级 canonical 文档：`docs/admin/README.md`

## 当前子项目

1. `admin-front/`: 平台管理员前端控制台
2. `gateway-admin/`: 平台管理员后端控制面 API

## 说明

本文件现在只保留工作区入口信息。
后台产品架构、RBAC、审批、审计、财务运营与部署规则统一维护在根 `docs/admin/` 和 `docs/03_Projects/`。
